# Ecommerce Sales Analysis Project

## Project Overview
This project provides a comprehensive analysis of e-commerce sales data. It tracks key performance indicators (KPIs), year-over-year growth, and regional sales distribution to help stakeholders make data-driven decisions.

## Key Insights from the Data
Based on the analysis of ~10,000 transactions:
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Top Performing Category:** **Technology** ($836,154 in sales).
- **Top Sales Region:** **California** followed by **New York** and **Texas**.

## Analysis Components
The Excel report includes several advanced visualizations:
1. **KPI Dashboard:** Tracks Sales, Profit, and Quantity trends.
2. **Year-Over-Year (YoY) Analysis:** Compares performance across 2011-2014.
3. **Monthly Trend Analysis (Combo Chart):** Visualizes the relationship between Sales and Profit margins.
4. **Category Distribution (Donut Chart):** Shows the market share of Technology (59%), Furniture (21%), and Office Supplies (20%).
5. **Geographical Map:** Highlights high-performing states.
6. **Profit Analysis (Waterfall Chart):** Breaks down how each category contributes to the total bottom line.

## Files in this Repository
- `Ecommerce Sales Analysis.xlsx`: The main interactive Excel workbook.
- `Data Source`: Contains customer segments, shipping modes, and product details.

## How to Use
1. Download the `.xlsx` file.
2. Open in Microsoft Excel.
3. Use the Slicers (if applicable) to filter data by Year or Region.
